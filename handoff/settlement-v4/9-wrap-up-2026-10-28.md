## 3. Why AFC still can't settle

The desktop's `node.env` pins its rulesets:

```
RULESETS=./rulesets/agent-fighter.v1.js,./rulesets/pickle-brawl.v1.js,./rulesets/flood-control.v1.js
```

0.12.3 ships `rulesets/afc.v1.js`, and the file is in the desktop install, but the node only loads what this line names. The fix is your `node.env` call:

1. Append `,./rulesets/afc.v1.js` to `RULESETS`, or delete the line so the node loads every ruleset it ships.
2. Restart the node with `POST /restart` from loopback, or the Nodes page.
3. Check that `/health` lists `afc.v1`.
4. Then the AFC session can settle its queued bout.

Deleting the line would also load `tug.v1`.
